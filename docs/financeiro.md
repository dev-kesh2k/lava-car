# Administrativo e financeiro

- **Painel** (`/admin`): faturamento (OS pagas), carros lavados (Pronto/Entregue), ticket médio, mês até agora, barras diárias e top 5 serviços. Hoje ou mês.
- **Serviços** (`/admin/servicos`): matriz serviço × porte. Preço vazio = serviço não aparece para aquele porte.
- **Equipe** (`/admin/equipe`): papel, % de comissão e ativo. Funcionário novo entra no app uma vez e o dono o torna operador.
- **Comissões:** semana de segunda a domingo; cada funcionário recebe o % sobre o valor das OS que concluiu (quem começou a lavagem fica como responsável). Botão copia o recibo para mandar no WhatsApp.
- **Caixa** (`/admin/caixa`): entradas automáticas das OS pagas + despesas manuais por categoria (produtos, água, energia...). Entradas de OS não podem ser apagadas à mão — estorne a OS.
